# PictureScraper

Hello everyone,
This is a quick code in Python created to download pics from a website. The way it works it can be described as, you want some pictures from a website, and you notice that the links of each picture follows a pattern.

For example: 
hello-scheme-1.jpg
hello-scheme-2.jpg
hello-scheme-3.jpg
hello-scheme-4.jpg

It happened to me in a WordPress website a few days ago. That website wouldn't let me see all the pictures easily so I created that script. You'll need to modify the link in the code in order to make it work, also if you know how many pictures are with that same name you should modify the for loop so it'll stop right in the last position instead of giving error for several more loops.

Pictures will appear downloaded automatically in the Visual Studio Code Folder in case you're using VSC, you can also modify that you save them in Desktop.
